# Property Edit Page - Структура

Эта страница декомпозирована на более мелкие, управляемые компоненты для улучшения читаемости и поддержки кода.

## Структура файлов

```
[id]/
├── page.tsx                    # Главный компонент страницы
├── types.ts                    # TypeScript типы и интерфейсы
├── constants.ts                # Константы (опции селектов, начальные значения)
├── usePropertyForm.ts          # Хук для управления состоянием формы
├── sections/                   # Компоненты секций формы
│   ├── index.ts               # Экспорт всех секций
│   ├── BasicInfoSection.tsx   # Основная информация (название, цена, описание)
│   ├── LocationSection.tsx    # Адресная информация
│   ├── PropertyDetailsSection.tsx  # Детали недвижимости (комнаты, площадь)
│   ├── FeaturesSection.tsx    # Дополнительные характеристики (мизоз, лифт)
│   ├── MapSection.tsx         # Выбор местоположения на карте
│   └── ImagesSection.tsx      # Загрузка изображений
└── README.md                   # Этот файл
```

## Компоненты

### page.tsx
Главный компонент, который:
- Управляет общим состоянием страницы
- Рендерит все секции формы
- Обрабатывает отправку формы

### types.ts
Содержит:
- `PropertyForm` - интерфейс данных формы
- `PropertyFormSectionProps` - общий интерфейс для props секций

### constants.ts
Содержит:
- `INITIAL_FORM` - начальные значения формы
- Все опции для селектов (города, типы недвижимости и т.д.)

### usePropertyForm.ts
Кастомный хук, который:
- Управляет состоянием формы
- Загружает данные недвижимости (для режима редактирования)
- Сохраняет изменения на сервер
- Обрабатывает автозаполнение адреса с карты

### Секции (sections/)

Каждая секция - это изолированный компонент, который:
- Принимает `formData` и `handleChange` через props
- Отвечает за рендеринг определенной части формы
- Можно легко переиспользовать или изменить независимо

## Использование

```tsx
import { usePropertyForm } from './usePropertyForm';
import { BasicInfoSection, LocationSection, ... } from './sections';

// В компоненте:
const { formData, handleChange, ... } = usePropertyForm(id, isNew, form);

<BasicInfoSection formData={formData} handleChange={handleChange} />
```

## Преимущества декомпозиции

1. **Читаемость**: Главный файл теперь ~100 строк вместо ~700
2. **Поддержка**: Легко найти и изменить конкретную секцию
3. **Переиспользование**: Секции можно использовать в других формах
4. **Тестирование**: Каждую секцию можно тестировать независимо
5. **Совместная работа**: Разные разработчики могут работать над разными секциями
