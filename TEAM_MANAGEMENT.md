# Управление командой - Инструкция

## 🎯 Что сделано

Система управления командой полностью настроена и работает с базой данных. Теперь все изменения в команде происходят через админ-панель, и данные автоматически отображаются на сайте.

## 📊 Структура

### База данных
- **Owner** - Владельцы/Основатели компании (Рам Мзрхи, Хаим Энби)
- **TeamMember** - Сотрудники/Агенты (Томер Гал, Лиор Гамиш)

### API Endpoints
- `GET /api/owners` - Получить всех владельцев (публичный)
- `GET /api/team` - Получить всех членов команды (публичный)
- `GET /api/admin/owners` - Управление владельцами (админ)
- `GET /api/admin/team` - Управление командой (админ)

## 🚀 Как использовать

### 1. Доступ к админ-панели

Откройте в браузере:
```
http://localhost:3000/admin
```

Войдите используя ваши учетные данные.

### 2. Управление владельцами (Основатели)

**URL:** `/admin/owners`

Вы можете:
- ✏️ **Редактировать** - изменить имя, фото, телефон, email, WhatsApp, описание
- ➕ **Добавить нового** - кнопка "הוסף בעלים חדש"
- 🗑️ **Удалить** - удалить владельца
- 🔄 **Активировать/Деактивировать** - показывать/скрывать на сайте
- 📊 **Изменить порядок** - поле "סדר" определяет порядок отображения

### 3. Управление командой (Агенты)

**URL:** `/admin/team`

Вы можете:
- ✏️ **Редактировать** - изменить имя, должность, фото, телефон, мобильный, факс, email, описание
- ➕ **Добавить нового** - кнопка "הוסף חבר צוות חדש"
- 🗑️ **Удалить** - удалить члена команды
- 🔄 **Активировать/Деактивировать** - показывать/скрывать на сайте
- 📊 **Изменить порядок** - поле "סדר" определяет порядок отображения

### 4. Загрузка фотографий

При редактировании/создании:
1. Нажмите на поле изображения
2. Выберите файл с компьютера
3. Изображение автоматически загрузится на сервер
4. Путь к изображению сохранится в базе данных

## 📝 Поля данных

### Владельцы (Owner)
- **Имя** (name) - обязательное
- **Должность** (title) - например, "מייסד ומתווך נדל״ן"
- **Фото** (image) - путь к изображению
- **Телефон** (phone)
- **Email** (email)
- **WhatsApp** (whatsapp)
- **Описание** (description)
- **Порядок** (order) - число для сортировки
- **Активен** (isActive) - показывать на сайте или нет

### Члены команды (TeamMember)
- **Имя** (name) - обязательное
- **Должность** (role) - например, "סוכן נדל״ן"
- **Фото** (image) - путь к изображению
- **Телефон** (phone)
- **Мобильный** (mobile)
- **Факс** (fax)
- **Email** (email)
- **Описание** (description)
- **Порядок** (order) - число для сортировки
- **Активен** (isActive) - показывать на сайте или нет

## 🔄 Как это работает

1. **Вы меняете данные в админке** → Нажимаете "Сохранить"
2. **Данные сохраняются в базу** → SQLite база данных
3. **Сайт автоматически показывает новые данные** → Компоненты подтягивают из API

## 📂 Файлы проекта

### База данных
- `prisma/schema.prisma` - Схема базы данных
- `dev.db` - SQLite база данных

### API
- `src/app/api/owners/route.ts` - API для владельцев (публичный)
- `src/app/api/team/route.ts` - API для команды (публичный)
- `src/app/api/admin/owners/route.ts` - CRUD для владельцев (админ)
- `src/app/api/admin/team/route.ts` - CRUD для команды (админ)

### Компоненты
- `src/components/about/AboutOwners.tsx` - Отображение владельцев на странице "О нас"
- `src/components/about/AboutTeam.tsx` - Отображение команды на странице "О нас"

### Админ-панель
- `src/app/admin/owners/page.tsx` - Список владельцев
- `src/app/admin/owners/[id]/page.tsx` - Редактирование владельца
- `src/app/admin/team/page.tsx` - Список команды
- `src/app/admin/team/[id]/page.tsx` - Редактирование члена команды

## 🛠️ Полезные команды

```bash
# Добавить начальные данные в базу
node scripts/seed-team.mjs

# Открыть Prisma Studio для просмотра базы данных
npx prisma studio

# Пересоздать базу данных (ОСТОРОЖНО! Удалит все данные)

```

## ✨ Примеры использования

### Добавить нового агента
1. Перейдите на `/admin/team`
2. Нажмите "הוסף חבר צוות חדש"
3. Заполните данные:
   - Имя: שרה כהן
   - Должность: סוכנת נדל״ן
   - Загрузите фото
   - Телефон: 050-123-4567
   - Email: sarah@example.com
   - Описание: краткая биография
4. Нажмите "שמור"

### Изменить телефон владельца
1. Перейдите на `/admin/owners`
2. Найдите владельца в списке
3. Нажмите кнопку "ערוך"
4. Измените номер телефона
5. Нажмите "שמור"

### Скрыть члена команды
1. Перейдите на `/admin/team`
2. Найдите члена команды
3. Переключите переключатель "פעיל/כבוי" в положение "כבוי"
4. Данные останутся в базе, но не будут показываться на сайте
