# Очистка несуществующих изображений из базы данных

## Проблема

В базе данных есть ссылки на изображения, которые физически отсутствуют на сервере.
Это вызывает ошибки:
```
⨯ The requested resource isn't a valid image for /uploads/properties/...
```

## Решение

### 1. Запустить скрипт очистки на production сервере

```bash
# Подключиться к серверу
ssh root@appartment-project

# Перейти в директорию проекта
cd /opt/apartment-project

# Запустить скрипт очистки
npm run clean:images
```

Скрипт:
- Проверит все изображения в базе данных
- Удалит ссылки на несуществующие файлы
- Оставит только те изображения, которые физически существуют в `public/uploads/`

### 2. Синхронизация файлов между dev и production

**Важно:** Папка `public/uploads/` не синхронизируется через git!

#### Скачать файлы с сервера на локальную машину:

```bash
# Из локальной папки проекта
rsync -avz --progress root@your-server:/opt/apartment-project/public/uploads/ ./public/uploads/
```

#### Загрузить файлы с локальной машины на сервер:

```bash
# Из локальной папки проекта
rsync -avz --progress ./public/uploads/ root@your-server:/opt/apartment-project/public/uploads/
```

### 3. После очистки - перезапустить приложение

```bash
pm2 restart apartment-project
```

## Предотвращение проблемы в будущем

### Вариант 1: Облачное хранилище (рекомендуется)

Переместить загрузку файлов в облачное хранилище:
- AWS S3
- Cloudinary
- DigitalOcean Spaces

### Вариант 2: Синхронизация при деплое

Добавить в скрипт деплоя синхронизацию папки uploads перед обновлением кода.

### Вариант 3: Общее хранилище

Использовать монтированную папку или NFS для хранения файлов отдельно от кода.
